# RELEX download page

Static page served by Render (see `render.yaml` at the repo root).

The download button points at GitHub Releases:
`https://github.com/rakiibull/RELEX/releases/latest/download/RELEX-<version>.dmg`

After cutting a new release, update the version in that link and the size in
the line beneath the button.

Images are generated from the app itself rather than mocked up: `popup.png` is
a real capture of the reminder window, `icon.png` comes from `build/icon.icns`.
